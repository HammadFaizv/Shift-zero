EVIDENCE ASSETS - Captain Halcyon / The Right Angle

svg/  Editable vectors. Open in Inkscape. Every shape is its own object.
png/  Transparent PNGs at 2x size (backgrounds are opaque 1280x1280).
      Open in Pinta, Krita, GIMP or mtPaint.

See LEVEL_ASSETS.md for which files go with which case.

Tips
- Pinta is the closest thing to MS Paint on Linux (sudo apt install pinta).
- Day and night backgrounds share the same layout, so you can swap them
  without moving anything. To look like evidence photos, desaturate and add grain.
- Flip any character horizontally in your editor to face the other way.
- Speech bubble text is editable in the SVG files.
